# 第21届全国大学生智能汽车竞赛: 蚂蚁搬家组 Q&A 清洗版

> 来源: `https://zhuoqing.blog.csdn.net/article/details/157686623`
>
> 说明: 仅保留规则相关问答,去除页面噪声.

## 1. 2026年2月问答

### QA-202602-02
- 问: 辅助车模可以在黄色胶带边界外行走吗?
- 答: 可以.

### QA-202602-05
- 问: 辅助车模可以用 OpenART 吗?
- 答: 不可以.辅助车模按规则使用 STC.

### QA-202602-09
- 问: 可以使用 UWB 定位吗?
- 答: 允许.

### QA-202602-14
- 问: 辅助车可否进入 `1m x 1m` 物品区?计时从何时开始?
- 答: 可进入但不可触碰物体;计时从搬运车启动开始.

## 2. 2026年3月问答

### QA-202603-01
- 问: 双车推物时若出现瞬间只有一车接触,是否有效?
- 答: 瞬间不同步接触允许;若长期只有一车推动,不符合要求.

### QA-202603-06
- 问: 外形 `<30cm` 是否包含高度?
- 答: 搬运车高度无专门限制.

## 3. 开发落地澄清（速查）

- 规则主线: 双车协同、单件搬运、返回发车区、计时闭环.
- 平台主线: 搬运主控 `NXP-MicroPython`,辅助车 `STC`.
- 场地主线: 预赛和决赛障碍配置不同,决赛复杂度更高.
- 合规主线: Q&A 可对细则进行解释和补充,工程实现需同步引用.
