# 第21届全国大学生智能汽车竞赛（蚂蚁搬家组）题面整理

> 整理目标: 将远端网页规则转换为仓库内可读 Markdown,便于 Agent 直接检索.
>
> 来源: 总则 + 蚂蚁搬家细则（详见 `docs/problem_statement/sources.md`）.

## 1. 使用方式

- 开发前先阅读「第 4 章 REQ 编号索引」.
- 讨论实现方案时,直接引用 REQ 编号（例如 `REQ-ANT-007`）.
- 若规则与 Q&A 冲突,以最新官方问答澄清为准,并在 `qa.md` 中核对.

## 2. 总则（与本项目相关摘录）

- 蚂蚁搬家属于缩微赛道,允许自制车模.
- 搬运过程要求双车协同,物体搬运中不得离地.
- 主搬运车模平台为 `NXP-MicroPython`,辅助车按细则执行.
- 规则在 `2026-06-15` 前持续修订,之后冻结.

## 3. 蚂蚁搬家细则（清洗版）

- 每次只允许搬运 1 件物品.
- 不允许单车全程独立完成搬运.
- 推杆长度不超过 `10cm`,垂直尺寸不超过 `5cm`.
- 车模整体（含推杆）外形尺寸小于 `30cm`.
- 物体越过黄色边界线即算成功.
- 决赛存在凸起与砖块障碍.

## 4. 面向开发的 REQ 编号索引

### 4.1 总则类（REQ-GEN）

- `REQ-GEN-001`: 本组属于缩微赛道,允许自制车模.
- `REQ-GEN-002`: 缩微组重量规则有效,超 `100g` 部分按“克数/20”折算罚时.
- `REQ-GEN-003`: 蚂蚁搬家主搬运车模主控采用 `NXP-MicroPython`.
- `REQ-GEN-010`: 规则在 `2026-06-15` 前可能修订,开发文档需标记版本时间.

### 4.2 细则类（REQ-ANT）

- `REQ-ANT-001`: 必须有两辆搬运车模参与搬运任务.
- `REQ-ANT-007`: 中心物品区为 `1m x 1m`,物品间距至少 `10cm`.
- `REQ-ANT-009`: 每次只能搬运 1 件物品.
- `REQ-ANT-010`: 不允许单车全程独立完成搬运.
- `REQ-ANT-011`: 推杆长度不超过 `10cm`.
- `REQ-ANT-012`: 推杆垂直尺寸不超过 `5cm`.

### 4.3 问答澄清类（REQ-QA）

> 详细条目见 `docs/problem_statement/qa.md`.

- `REQ-QA-001`: 辅助车可在边界外运动.
- `REQ-QA-004`: 辅助车不允许使用 OpenART.
- `REQ-QA-005`: 可使用 UWB 定位.
- `REQ-QA-008`: 双车瞬间不同步接触可接受,长期单车推动不合规.
